# JSON 格式化工具

📝 線上 JSON 格式化、驗證與修復工具

## 🌐 網站網址
https://lance70176.github.io/json-formatter/

## ✨ 功能特色

- 🔧 **JSON 格式化** - 自動排版，易於閱讀
- ✅ **格式驗證** - 即時檢查 JSON 語法
- 🔤 **中文亂碼修復** - 自動轉換 \uXXXX 編碼為中文
- 🔃 **鍵名排序** - 可選排序物件鍵名
- 💾 **記錄儲存** - 自動儲存最近 20 筆記錄（localStorage）
- 🎨 **語法高亮** - 彩色標示鍵名、字串、數值等
- 📱 **響應式設計** - 支援各種裝置

## 🚀 使用方法

1. 在上方文字框貼上 JSON 內容
2. 勾選需要的選項（修復中文亂碼、排序鍵名）
3. 點擊「格式化」按鈕
4. 在下方查看格式化結果

## 🛡️ 隱私說明

- 純前端處理，所有資料都在瀏覽器內處理
- 不會傳送到任何伺服器
- 記錄儲存在 localStorage，僅存在你的裝置上
